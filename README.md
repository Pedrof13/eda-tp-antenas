# Trabalho Prático EDA - Antenas
Este projeto foi desenvolvido no âmbito da unidade curricular Estruturas de Dados Avançadas no ano letivo 2024/2025,
com objetivo de sedimentar os conhecimentos relativos à definição e manipulação de estruturas de dados dinâmicas e também a grafos na linguagem de programação C.

## Contexto do problema
Pretende-se considerar uma cidade com várias antenas. Cada antena é sintonizada numa frequência específica indicada por um caracter. O mapa das antenas com as suas localizações (coordenadas na matriz) e frequências é representado através de uma matriz.

## Estrutura de diretórios do projeto
```
eda-tp-antenas/
│
├── docs/       # Documentação de código
├── include/    # Ficheiros header
├── lib/        # Biblioteca
├── src/        # Código fonte
├── makefile    # Script de compilação
└── README.md   # Documentação do projeto
```

## Comandos
A partir da raiz do projeto pode executar os seguintes comandos:

### Execução do programa
```bash
make
```

### Gerar documentação doxygen
```bash
cd docs/doxygen
doxygen doxyfile
```
